# Open Source Projects

This curated index tracks major open-source projects relevant to cloud-native engineering and AI infrastructure. Use this guide to discover durable, widely adopted tools and platforms for architecture, operations, and innovation.

## How to Use This Index

- Projects are grouped by primary focus area.
- Each entry includes a rationale for inclusion, a focus tag, and a direct URL to the official project homepage or documentation.
- Selection emphasizes active maintainership, architectural significance, and production adoption.

## Selection Criteria

- Active maintainership
- Architectural significance
- Production adoption evidence
- Vendor-neutral governance

- **[Kubernetes – CNCF](https://kubernetes.io/)**  
  [Orchestration]  
  *Rationale:* De facto standard for container orchestration, automation, and scaling in cloud-native environments.

- **[Terraform – HashiCorp](https://www.terraform.io/)**  
  [Infrastructure as Code]  
  *Rationale:* Widely adopted tool for declarative infrastructure provisioning across clouds.

## Observability

- **[Prometheus – CNCF](https://prometheus.io/)**  
  [Observability]  
  *Rationale:* Leading open-source monitoring and alerting toolkit for cloud-native systems.

- **[Jaeger – CNCF](https://www.jaegertracing.io/)**  
  [Observability]  
  *Rationale:* Distributed tracing platform for monitoring and troubleshooting microservices.
