# Certifications

This curated index maps certifications to competencies and expected engineering depth for cloud-native, reliability, platform, security, and AI/ML roles. Use this guide to identify certifications with strong skill transfer and conceptual coverage.

## How to Use This Index

- Certifications are grouped by primary focus area.
- Each entry includes a rationale for inclusion, a focus tag, and a direct URL to the official certification page.
- Selection emphasizes skill transfer, conceptual coverage, and assessment quality.

## Selection Criteria

- Skill transfer to real production systems
- Vendor-neutral conceptual coverage where possible
- Assessment quality and transparency

## Cloud Architecture

- **["Certified Kubernetes Administrator (CKA)" – CNCF](https://www.cncf.io/certification/cka/)**  
  [Cloud Architecture]  
  *Rationale:* Industry-standard certification for Kubernetes operations, automation, and troubleshooting.

- **["AWS Certified Solutions Architect – Associate" – AWS](https://aws.amazon.com/certification/certified-solutions-architect-associate/)**  
  [Cloud Architecture]  
  *Rationale:* Broad coverage of cloud architecture principles, design patterns, and trade-offs.

## Reliability & Operations

- **["Google Professional Cloud DevOps Engineer" – Google Cloud](https://cloud.google.com/certification/devops-engineer)**  
  [Reliability]  
  *Rationale:* Focuses on SRE, monitoring, incident response, and reliability engineering in cloud environments.

## Platform Engineering

- **["Platform Engineering Professional" – Humanitec (Beta)](https://humanitec.com/certification/platform-engineering-professional)**  
  [Platform Engineering]  
  *Rationale:* Emphasizes platform-as-a-product, internal developer platforms, and automation.

## Security

- **["Certified Cloud Security Professional (CCSP)" – (ISC)²](https://www.isc2.org/Certifications/CCSP)**  
  [Security]  
  *Rationale:* Comprehensive coverage of cloud security concepts, architecture, and risk management.

## AI/ML

- **["TensorFlow Developer Certificate" – Google](https://www.tensorflow.org/certificate)**  
  [AI/ML]  
  *Rationale:* Demonstrates practical skills in building and deploying ML models in production.
